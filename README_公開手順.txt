漫画本棚ビューア Ver.1.0 GitHub Pages公開用

推奨リポジトリ名: manga-bookshelf
1. GitHubでPublicリポジトリ manga-bookshelf を作成
2. このフォルダのファイルをすべてリポジトリの最上位にアップロード
3. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save
4. https://stsnwi-ai.github.io/manga-bookshelf/ でアクセス（公開反映後）

漫画の画像ファイルはGitHubにアップロードしないでください。利用者の端末から選択する方式です。
注意: これはホーム画面用アイコンとマニフェストを追加した版です。オフライン利用を保証するサービスワーカーは含みません。
